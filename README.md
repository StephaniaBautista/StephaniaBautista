# Hola, soy Ivar Alexander.

### Desarrollo software para conectar ideas con experiencias útiles.

Soy desarrollador full stack. Me interesa construir productos completos: desde una interfaz que se sienta clara hasta las APIs, los datos y las integraciones que la hacen funcionar. También me gusta explorar cómo la tecnología puede acompañar algo muy humano: **leer, escribir y crear historias**.

---

## Una mirada a mis proyectos

### [Archivum · escritura creativa](https://github.com/StephaniaBautista/app-escritura)
Una plataforma en desarrollo para escritores, con editor, organización de personajes y universos, y herramientas de asistencia con IA. Un espacio donde se encuentran la narrativa y el software.

`TypeScript`  `React`  `Node.js`  `PostgreSQL`

### [Biblioteca de documentos](https://github.com/StephaniaBautista/ao3-document-library)
Una biblioteca para organizar y leer PDF, EPUB y HTML, con opciones de lectura, progreso y preparación para acceso sin conexión. Un proyecto nacido del interés por hacer más cómoda la experiencia de lectura.

`TypeScript`  `Web`  `Lectura digital`

### [Apoyo tutorial · residencias profesionales](https://github.com/StephaniaBautista/proyecto-residencias-profesionales)
Un prototipo para apoyar el seguimiento académico con datos sintéticos, alertas explicables y un asistente basado en documentos institucionales. Las reglas de seguimiento permanecen visibles y la decisión corresponde a las personas.

`TypeScript`  `Python`  `PostgreSQL`
